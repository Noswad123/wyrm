You can enter the following command to set it up;

[Click me to know where is HOTKEYS_PATH](/configure/config-file-path#hotkeys)

```bash
$EDITOR HOTKEYS_PATH
```

:::caution

Please do not use hotkeys with ascii codes conflicting with keys used to control wyrm:

- `Ctrl+M` - conflicts with `Enter` Key
- `Ctrl+I` - conflicts with `Tab` Key
- `Ctrl+?`, `Ctrl+[` - conflicts with `Delete` and `Backspace` Key

:::

### Default wyrm hotkeys

:::caution

If you are a vim user, the default hotkeys may make you hate wyrm.

:::

wyrm default hotkeys design concept:

- All hotkeys that will change to files use `ctrl+key` (As long as you don't press ctrl your files will always be safe).
- Non-control file classes use the first letters of words as hotkeys.
