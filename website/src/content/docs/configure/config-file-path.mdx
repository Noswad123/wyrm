## Directories

#### Config directory

|         Linux         |                   macOS                   |          Windows           |
| :-------------------: | :---------------------------------------: | :------------------------: |
| `~/.config/wyrm` | `~/Library/Application Support/wyrm` | `%LOCALAPPDATA%/wyrm` |

#### Theme directory

|            Linux            |                      macOS                      |             Windows              |
| :-------------------------: | :---------------------------------------------: | :------------------------------: |
| `~/.config/wyrm/theme` | `~/Library/Application Support/wyrm/theme` | `%LOCALAPPDATA%/wyrm/theme` |

#### Data directory

|           Linux            |                   macOS                    |          Windows           |
| :------------------------: | :----------------------------------------: | :------------------------: |
| `~/.local/share/wyrm` | `~/Library/Application Support/wyrm/` | `%LOCALAPPDATA%/wyrm` |

### Changing Config File Path

You can use the `-c` or `--config-file` flag to specify a different path for the `config.toml` file:

```bash
wyrm -c /path/to/your/config.toml
```

You can use the `--hotkey-file` flag to specify a different path for the `hotkey.toml` file:

```bash
wyrm --hotkey-file /path/to/your/hotkey.toml
```

#### Log directory

|           Linux            |                   macOS                   |          Windows           |
| :------------------------: | :---------------------------------------: | :------------------------: |
| `~/.local/state/wyrm` | `~/Library/Application Support/wyrm` | `%LOCALAPPDATA%/wyrm` |
