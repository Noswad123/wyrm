## Before install

First make sure you have the following tools installed on your machine:

- [Any Nerd-font ](https://www.nerdfonts.com/font-downloads), and set the font for your terminal application to use the installed Nerd-font

:::tip

If you don't install `Nerd font`, wyrm will still work, but the UI may look a bit off. It's recommended to disable the Nerd font option to avoid this issue.

:::

## Installation Scripts

Copy and paste the following one-line command into your machine's terminal.

### Linux / macOS

With `curl`:

```bash
bash -c "$(curl -sLo- https://wyrm.dev/install.sh)"
```

Or with `wget`:

```bash
bash -c "$(wget -qO- https://wyrm.dev/install.sh)"
```

Use `Wyrm_INSTALL_VERSION` to specify a version :

```bash
Wyrm_INSTALL_VERSION=1.2.1 bash -c "$(curl -sLo- https://wyrm.dev/install.sh)"
```

### Windows

With `powershell`:

```bash
powershell -ExecutionPolicy Bypass -Command "Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://wyrm.dev/install.ps1'))"
```

:::note

To uninstall, run the above `powershell` command with the modified URL:

`https://wyrm.dev/uninstall.ps1`

:::

Use `Wyrm_INSTALL_VERSION` to specify a version :

```bash
powershell -ExecutionPolicy Bypass -Command "$env:Wyrm_INSTALL_VERSION=1.2.1; Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://wyrm.dev/install.ps1'))"
```

With [Winget](https://winget.run/):

```powershell
winget install --id Noswad123.wyrm
```

With [Scoop](https://scoop.sh/):

```bash
scoop install wyrm
```

## Community maintained packages

[![Packaging status](https://repology.org/badge/vertical-allrepos/wyrm.svg)](https://repology.org/project/wyrm/versions)

> Sort by letter

### Arch

###### Builds package from sources

```bash
sudo pacman -S wyrm
```

###### Builds most recent version from GitHub

```bash
yay -S wyrm-git
```

### Homebrew

Install [Homebrew](https://brew.sh/) and then run the following command:

```bash
brew install wyrm
```

### NixOS

###### Install with nix command-line

```bash
nix profile install github:Noswad123/wyrm#wyrm
```

###### Install with flake

Add wyrm to your flake inputs:

```nix
inputs = {
  wyrm = {
    url = "github:Noswad123/wyrm";
  };
  # ...
};
```

Then you can add it to your packages:

```nix
let
  system = "x86_64-linux";
in {
  environment.systemPackages = with pkgs; [
    # ...
    inputs.wyrm.packages.${system}.default  ];
}
```

### Pixi

Install [Pixi](https://pixi.sh/latest/) and then run the following command:

```bash
pixi global install wyrm
```

### X-CMD

[x-cmd](https://www.x-cmd.com/) is a **toolbox for Posix Shell**, offering a lightweight package manager built using shell and awk.

```sh
x env use wyrm
```

## Start wyrm

After completing the installation, you can restart the terminal (if necessary).

Run `wyrm` to start wyrm

```bash
wyrm
```
